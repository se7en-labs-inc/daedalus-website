---
title: MacOS PGP署名検証手順
---
<ol>
  <li>
    Daedalusインストーラの.pkgファイルとそれに対応する.pkg.ascシグネチャファイルの両方を入手し、同じディレクトリに置きます。
  </li>
  <li>
    GPG Suiteが既にインストールされており、個人キーが生成されている場合は、手順5に進みます。そうでない場合は、次の手順に進みます。
  </li>
  <li>
    <a href='https://gpgtools.org' target='_blank'>https://gpgtools.org</a> にアクセスして、GPG Suiteセクションに進み、.dmgファイルをダウンロードしてインストールします。
    <ul>
      <li>
        .dmgファイルを右クリックしてから「開く」をクリックすると、2つのアイコンを持つ新しいウィンドウが開きます。
      </li>
      <li>
        「インストール」アイコンを右クリックして、「アプリケーションから開く」 - >「インストーラー」を選択すると、GPG Suiteインストーラーが起動します。
      </li>
      <li>
        インストールウィザードをたどる
      </li>
    </ul>
  </li>
  <li>
    GPG Suiteのインストールが完了すると、新しい鍵のペアを作成するように求められます（これは手順6に必要なので、スキップしないでください）。
    <ul>
      <li>
        自分に合った名前とメールアドレスを入力してください。
      </li>
      <li>
        あなたの個人鍵を保護するためにパスフレーズを選択してください（注：パスフレーズは空でもかまいませんが、将来この鍵とGPG Suiteを使用する予定がある場合はお勧めできません）。
      </li>
    </ul>
  </li>
  <li>
    GPGキーチェーンアプリケーションを使用してIOHKキーをインポートします。
    <ul>
      <li>
        アプリケーションメニューで、「キー」 - >「鍵サーバー上の鍵の検索」を選択します。
      </li>
      <li>
        signing.authority@iohk.ioを検索してください。
      </li>
      <li>
        ユーザーIDが「IOHK Signing Authority <signing.authority@iohk.io>」のフィンガープリントCBFAA9BAを持つキーを選択し、[Retrieve Key]をクリックします。
      </li>
      <li>
        インポートされたキーのフィンガープリントがD325 87D4 090F E461 CAEE 0FF4 966E 5CB9 CBFA A9BAであることを確認（インポートされたキーを右クリックしてから[詳細]）します。
      </li>
      <li>
        そうでない場合、間違ったキーがインポートされました。右クリックして削除
      </li>
      <li>
        もしそうなら、私たちは次のステップに進むことをお勧めします。
      </li>
    </ul>
  </li>
  <li>
    インポートされたIOHKキーに署名します（これは信頼を指定し、次のステップに必要です）。
    <ul>
      <li>
        インポートしたIOHKキーを右クリックしてから、[署名]をクリックします。
      </li>
    </ul>
  </li>
  <li>
    インストーラバイナリを確認します。
    <ul>
      <li>
        FinderでDaedalusインストーラ（.pkgファイル）を右クリックし（.ascファイルを右クリックしないでください、正しく機能しません）、[サービス]  - > [OpenPGP]の順に選択します。 同じディレクトリ）
      </li>
      <li>
        [検証結果]ダイアログボックスが表示され、[結果]列に結果が表示されます。
        <ol>
          <li>
            「署名者：IOHK署名機関<signing.authority@iohk.io> 1471941A  - 完全信頼」 - 成功した場合
          </li>
          <li>
            他に何でもインストーラのための有効な署名がなかったことを意味します。
          </li>
        </ol>
      </li>
    </ul>
  </li>
</ol>
